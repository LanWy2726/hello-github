# hello-github

> 我的第一个 GitHub 仓库，用来把「本地 → GitHub → 网页」这条最短路径走通。

## 仓库内容

- `index.html` — 一个可以直接双击打开的静态页面，稍后会发布成 GitHub Pages 网站
- `README.md` — 本文件

| 提交身份 | 惜事旧梦 `<178462168+LanWy2726@users.noreply.github.com>` |

## 常用命令

```bash
git status              # 看当前状态
git add .               # 把改动放进暂存区
git commit -m "说明"     # 提交
git push                # 推到 GitHub
git log --oneline       # 看提交历史
```
